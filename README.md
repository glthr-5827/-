# OrbitPlan — Android app

Полноценное Flutter-приложение для Android, не WebView. Работает оффлайн и хранит данные локально на телефоне.

## Что внутри

- Главная панель
- Привычки
- Задачи
- Финансы
- Заметки
- Настройки темы и языка
- Русский и английский язык
- Случайное заполнение примером
- Локальные уведомления: ежедневные для привычек и по дате/времени для задач
- Без подписок, тарифов и платных ограничений

## Как получить APK через GitHub Actions

1. Создай новый репозиторий на GitHub.
2. Загрузи туда содержимое этой папки.
3. Открой вкладку **Actions**.
4. Выбери workflow **Build Android APK**.
5. Нажми **Run workflow**.
6. После завершения открой последний запуск и скачай artifact **orbitplan-debug-apk**.
7. Внутри будет `app-debug.apk` — его можно перекинуть на телефон через провод и установить.

## Как собрать локально

Нужно установить Flutter SDK. Потом в папке проекта выполнить:

```bash
flutter create --project-name orbitplan --org com.orbitplan --platforms=android .
python3 tools/patch_android.py
flutter pub get
dart run flutter_launcher_icons
flutter build apk --debug
```

APK появится здесь:

```text
build/app/outputs/flutter-apk/app-debug.apk
```

## Важно про уведомления

На Android 13+ приложение попросит разрешение на уведомления. На Android 12 уведомления работают без отдельного системного запроса. Некоторые телефоны Infinix/Tecno/Realme/Xiaomi могут ограничивать фоновые уведомления режимами энергосбережения. Для стабильных напоминаний разреши приложению автозапуск и работу в фоне в настройках батареи.
